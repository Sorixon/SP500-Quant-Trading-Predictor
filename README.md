## 📝 Project Description

### 🎯 Motivation & Objective
Financial time-series data is notoriously noisy, non-stationary, and driven by complex linear and non-linear relationships. Traditional algorithmic trading heavily relies on rigid technical analysis indicators (like RSI or VWAP). While easy to implement, these rule-based systems often fail during structural market regime shifts, leading to heavy drawdowns (the classic "catching a falling knife" phenomenon).

The core objective of this project was to design, backtest, and validate an **end-to-end Quantitative Trading Framework** on the S&P 500 index (`^GSPC`). The pipeline moves from a basic rule-based technical strategy to an optimized, non-linear **Machine Learning Classifier**, built with strict econometric controls to prevent data leakage and overfitting.

---

### 🧬 Methodological Workflow & Data Pipeline

#### 1. Data Ingestion & MultiIndex Handling
* Automated daily market data retrieval using the `yfinance` API.
* Implemented custom data-cleaning routines to properly flatten and parse MultiIndex headers generated by newer versions of Yahoo Finance, ensuring a robust downstream pipeline.

#### 2. Feature Engineering & Econometric Transformation
To build a statistically valid Machine Learning model, raw price data (which possesses a stochastic trend and violates stationarity) cannot be used directly. The framework engineers localized, relative, and stationary features using `pandas_ta`:
* **Relative Strength Index (RSI):** A 14-period bounded oscillator to capture overbought/oversold conditions.
* **VWAP Distance Drivers (`Dist_VWAP_M_%` & `Dist_VWAP_Y_%`):** Computes the exact percentage distance of the `Close` price from the Monthly and Yearly Volume Weighted Average Price. This transforms nominal price levels into stationary mean-reverting metrics.
* **Log Returns (`Return_%`):** Percentage daily price changes.

#### 3. Rigorous Stationarity Testing (ADF Test)
* Applied the **Augmented Dickey-Fuller (ADF) test** via `statsmodels` to scientifically verify the stationarity of all engineered features. 
* Checked that $p$-values for returns and distance drivers approached $0.0$, successfully rejecting the null hypothesis of a unit root, thereby validating the dataset for Time-Series Machine Learning.

#### 4. Machine Learning Implementation & Leakage Prevention
* **Target Labeling:** The model is tasked with predicting a binary classification target (`Target`): `1` if the next day's log return is positive, `0` if negative.
* **Anti-Leakage Split:** Instead of standard randomized K-Fold cross-validation (which destroys the temporal structure and leaks future information into the past), the data was split chronologically (80% Train / 20% Test).
* **Feature Pruning:** Nominal columns like `Price` or raw `Close` were explicitly dropped from the training matrix `X` to eliminate structural trend bias.
* **Model Optimization:** Trained a `Random Forest Classifier` with heavy regularizing constraints (`max_depth=4`, `min_samples_leaf=15`, `class_weight='balanced'`) to prevent the model from memorizing historical noise and to handle class imbalances.

#### 5. Interactive Business Intelligence (BI) Backtesting
The engineered signals and ML predictions were exported to Microsoft Power BI to build an interactive institutional-grade analytics dashboard:
* **Confusion Matrix Evaluation:** Dynamically maps out True Positives vs. False Positives to track the precision of the strategy.
* **Equity Curve Simulation:** Uses DAX (Data Analysis Expressions) to calculate time-series cumulative financial returns, exposing drawdown depths and recovery speeds.

---

### 💡 Key Findings & Analytical Conclusions
* **The Rule-Based Vulnerability:** Power BI backtesting revealed that the standard linear strategy (buying purely based on low RSI and price below Monthly VWAP) suffered severe drawdowns during market corrections because it kept buying into an extended downtrend.
* **The Predictive Alpha:** By applying a non-linear Machine Learning model on stationary indicators, the framework managed to filter out high-risk false signals. Achieving an **Out-of-Sample Accuracy of ~52.26%** on a highly efficient asset like the S&P 500 represents a statistically significant quantitative edge, flattening out major drawdowns on the cumulative equity curve.
